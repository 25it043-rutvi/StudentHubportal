About StudentHub Portal

Modern Full-Stack Academic Management Framework for CHARUSAT

🎯 Problem Definition & Project Vision

In modern educational institutions, academic announcements, extracurricular event registrations, departmental notices, and student profile management are frequently fragmented across disparate applications.

StudentHub addresses this challenge by providing a unified, secure, and responsive web portal built according to industry-standard web engineering principles. Students can track announcements, discover campus events, participate in hackathons, and monitor their profiles, while faculty administrators maintain full control over admissions, event lifecycles, and audit logging.

💻

Frontend Architecture

Built with Semantic HTML5, accessible ARIA roles, modern CSS Grid/Flexbox layouts, and client-side JavaScript for real-time validation and asynchronous Fetch API consumption.

⚙️

Backend Architecture

Engineered using PHP 8 with session fixation prevention, role-based access control (RBAC), automatic session timeouts, and secure RESTful JSON API endpoints.

🗄️

Database & Security

Relational MySQL schema with strict foreign keys, prepared statements via PDO/MySQLi to prevent SQL injection, and bcrypt password hashing (password_hash).

👥 User Roles & Responsibilities

🎓 Student Role

  • Register and log in securely.
  • Explore and filter upcoming campus events.
  • Register for events and view registered status.
  • Access profile details and departmental notices.
  • Submit feedback and search FAQ answers.

🛡️ Administrator Role

  • Comprehensive admin dashboard with live statistical cards.
  • Full CRUD operations on student accounts (with soft delete).
  • Full CRUD operations on events with poster image uploads.
  • Monitor user registrations and view audit log trails.
  • Toggle student activation statuses.
